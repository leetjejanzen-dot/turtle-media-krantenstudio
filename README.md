# Turtle Media Krantenstudio

Windows-app voor het maken van professionele meerpagina-kranten voor FiveM-mediabedrijven.

## Functies
- Meerdere krantenpagina's maken, dupliceren en verwijderen
- Eigen tekst, foto's, logo, kleuren en stijl
- Projecten lokaal opslaan en heropenen
- Hoge-resolutie PNG-export
- Printklare meerpagina-PDF
- Veilige automatische updates met SHA-256-controle
